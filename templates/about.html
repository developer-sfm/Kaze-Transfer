What Exactly Is Kaze Transfer?

Introduction

Kaze Transfer is a real-time system that lets users transfer files using simple hand gestures instead of clicks and menus. It is built using Python, web technologies such as HTML, CSS and JavaScript. It starts a server where opening and closing a hand can trigger file-sharing events.

Origin

Kaze Transfer was created as a "Fun" project solely by a student who wanted to build something that is visually interesting, challenging, and complex combining computer vision with modern web communication.

Behind The System

The system is split into 2 main parts, the Server and the Client sides. The server purely uses python with flask and socketio. Flask connects the backend(python) to the frontend(Web, html). Socketio is used to let the frontend and backend share data through Live connection. Python runs a function which captures the camera feed and processess it via openCV, Mediapipe. As soon as the function sees the hand open, screenshot is captured and the system awaits for the closed hand gesture.
The client side uses web technologies like HTML, CSS and JavaScript. The camera feed sends the live video in the form of frames to the backend and looks for a closed hand gesture until the screenshot is displayed onto the HTML.
